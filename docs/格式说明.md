# 实况文件实现与边界

- Apple: JPEG Exif 的 Apple MakerNote tag 17 与 MOV `com.apple.quicktime.content.identifier` 使用同一 UUID；MOV 写入 `mebx` timed metadata track，键为 `com.apple.quicktime.still-image-time`，通过时间编辑列表定位封面。
- Android: JPEG 主图 + 尾部 MP4，XMP Camera 描述动态照片和封面微秒时间戳，Container Directory 描述视频长度；文件以 `MP.jpg` 结尾。
- 先使用 FFmpeg 生成短片和封面，再封装。Apple MOV 重排媒体时重定位 chunk offsets，保持视频与音频可解码。
- 首版最长三秒，H.264 / AAC、30 FPS、SDR。Windows 预览使用相同封面与 MP4。
- 手机相册识别及社交平台接收均需要实际设备验证。当前不宣称已通过真机测试。
