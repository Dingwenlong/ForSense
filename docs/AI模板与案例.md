# AI 图片优化模板与案例

片语只提供本地素材管理、复制图片、复制提示词和手动导入结果。不会调用图像生成服务、保存 API 密钥或自动上传图片。外部 AI 工具的账号、模型与费用由使用者自行选择。

## 模板来源

创意模板参考数字生命卡兹克于 2026-09-28 发布的文章《我整理了 GPT-Image 2.5 的 12 种玩法，希望能承包你的整个假期朋友圈》：

[原文链接](https://mp.weixin.qq.com/s/WeWYRyyAJtdPrErIV7063A)

依据提供的文章长截图提取场景并改写提示词，未将文章截图或原文配图打包进应用。文章中的模型与操作说明属于其发表时的内容，应用不承诺特定模型的效果。

20 个模板包含文章涉及的去除背景游客、调光、美颜、拍立得公仔、明信片、主体贴纸、行李箱拼贴、人物海报、演唱会氛围、美食飞溅、物体文字涂鸦和画面注释，以及商品、美食、旅行、夜景、室内、宠物、旧照和组图色调等常用方向。

模板中的【占位内容】需要自行替换。多参考图模板会提示在外部 AI 工具追加参考图；片语一次复制一张图片，须逐张粘贴。案例和模板均可离线查看。

## 内置案例

案例制作日期：2026-09-28。工具：Codex 内置 imagegen；工具未返回具体模型版本，因此不标注为某一模型的测试结果。

- 商品柔光：先生成一张偏暗、偏黄的陶瓷杯产品照片，再将这张图片作为输入，使用应用中的 `product` 模板实际编辑。观察曝光、白平衡、材质和背景杂物的变化。
- 美食暖光：先生成一张平淡冷光下的牛油果吐司照片，再将这张图片作为输入，使用 `food` 模板实际编辑。观察食物色彩、纹理与餐盘高光。

四张图片保存于 `public/ai-examples/`，以 `before` / `after` 区分，未用 CSS 滤镜模拟 AI 编辑。它们是合成的演示素材，不是真实用户的照片，也不是应用自动调用服务生成的结果。界面标明此来源和效果边界。

生成原图时的内容要求：

- 商品：单个无品牌、象牙白哑光陶瓷杯，右侧圆把手，浅橡木厨房台面，三分之四角度；室内顶灯偏暗偏黄，背景有蓝色抹布与金属茶匙；真实手机摄影，无文字、拼图或水印，3:4 竖幅。
- 美食：白色圆盘上两片牛油果酸面包吐司、一半小番茄和芝麻菜，胡桃木咖啡桌，约 45 度俯拍；弱冷光、低对比、轻微灰暗色彩；真实食材纹理，无人物、文字、拼图或水印，4:3 横幅。

优化阶段使用的完整提示词为 `src/shared/prompt-templates.ts` 中的 `product` 与 `food`，界面中可展开查看并直接复制。

## 手动结果的记录

导入结果时复制为一个新素材，并记录对应原图 ID、模板 ID、完整提示词和导入时间。原图和旧版结果保留；原图即使归档，也仍能用于对比。原图与结果的尺寸可以不同，比较视图使用完整画面显示，不裁切或拉伸。

这些记录只说明用户把该图片作为结果导入，不证明外部工具实际采用了某个模型、提示词或参数。图片与文案导出包不包含本机路径或 AI 提示词记录。
