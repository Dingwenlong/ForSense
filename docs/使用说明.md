# 片语 · 图文工作台

片语用于在 Windows 电脑上整理朋友圈、抖音图文素材。素材管理、视频处理与导出在本机完成。AI 图片优化为离线辅助流程，由你在外部 AI 工具中手动处理，片语不自动上传素材。

0.1.1 使用无主题的基础界面，所有操作使用原生控件。实线标记表示当前草稿或已选选项，禁用控件表示当前操作不可用。已有草稿可直接继续使用。

0.2.0 保留“草稿列表 → 预览工作台”流程，并增加独立的“全局素材库”和“AI 图片优化”页面。工作台在微信／抖音预览卡片内直接添加图片和编辑文案；顶部工具条提供标题、平台、视频取材、复制文案及导出。切换页面及退出时会保存当前草稿。

图片仍可在预览中拖动重排，单击图片打开编辑弹窗裁切、旋转或移除。微信九宫格图片可按 Alt + 方向键排序；抖音画面可按 Alt + ← / → 排序。

## 开始使用

1. 运行安装包 `SocialCopyStudio-Setup.exe`，安装完成后打开片语。在草稿列表中选择已有草稿，或新建朋友圈／抖音图文。
2. 打开草稿后进入预览工作台。在顶部填写标题、选择平台；点击微信九宫格或抖音画面的“＋”占位，在弹窗中选择“从电脑导入图片”，或勾选已有素材后加入草稿。支持 JPG／PNG／WebP，也可拖入工作台。已有素材不会重复加入。
3. 按住预览图片拖到目标位置调整顺序；单击图片打开编辑弹窗，可旋转、裁切或移除。微信实况可用图片上的“实况”按钮另行播放。
4. 微信预览内可直接输入文案。抖音预览点击正文后输入，失焦即恢复带话题高亮的展示。顶部“复制文案”可一键复制，也可以只写文案不加图片。
5. 在同一页检查排版。朋友圈参考微信发表前的编辑页，显示文案、最多九张图片和发布设置栏；图片超过九张时，预览会提示并仍在导出包中保留全部。位置、提醒和可见范围在微信中设置。抖音参考图文帖子布局，显示竖图、页码、话题、完整文案及互动区示意。用上一张／下一张或左右方向键翻页；按住图片拖到进度条可直接调整顺序。话题和相关搜索来自文案中的 `#标签`，账号与互动区仅供位置参考。
6. 点击“导出素材包”，选择保存位置及文件夹或 ZIP 格式，开始导出。同名导出自动另存。

草稿自动保存。可以按标题或正文搜索、按平台筛选、复制草稿、重命名或删除。删除草稿前会确认。

## 从视频取材

点击“从视频取材”，选择 MP4 或 MOV 文件（H.264 或 H.265 编码）。准备阶段会在本机生成供预览、截图共用的视频，支持进度显示与取消。较长或高分辨率视频需要更多时间和磁盘空间。

- 截图：拖动时间轴，使用上一帧／下一帧微调，点击“截取并加入草稿”。
- 实况：切换“制作实况”，设定开始、结束和封面时间，片段最长 3 秒。可保留原声或静音，生成后加入草稿。
- 高动态范围视频转换为 SDR 以兼容预览和分享；裁切与旋转同样作用于实况封面和动态画面。
- 视频转实况在输出时规范化为 30 帧/秒，封面取自最终片段，时间以实际帧对齐。

## 全局素材库

顶部“全局素材库”可随时进入。现有草稿与历史处理中保留的素材会自动显示，不需要重新导入。图片、实况、视频和手动导入的优化结果均可复用；删除草稿不会删除素材。

- 搜索名称或优化提示词，按图片、实况、视频、收藏、优化结果和已归档筛选。
- 点击缩略图展开详情，可改名、收藏、复制图片或进入 AI 图片优化；实况可在详情中播放。
- 有打开的草稿时，勾选素材后点击“加入当前草稿”；也可在预览的“＋”弹窗中选择素材。
- 归档只隐藏素材库里的图片，不删除文件，不影响已经使用它的草稿。在“已归档”中可以恢复。
- “视频”分类可重新打开已导入视频进行截图和实况制作，不必再次转码。从素材库进入视频工具时，结果保存在素材库；从草稿进入时，同时加入草稿。

## AI 图片优化

片语不接入 AI 服务、不要求 API 密钥，也不会自动发送图片。可在顶部进入，或在预览图片的编辑弹窗、素材详情中选择“AI 图片优化”。

1. 选择原图：从素材库选一张静态图片，或从电脑导入一张原图。
2. 选择模板：20 个场景涵盖去除游客、调光、人像、商品、美食、旅行贴纸、明信片、海报、演唱会氛围等。切换模板会用新模板替换当前提示词，可先复制保存自己改过的内容。
3. 复制原图：点击“复制原图”，切换到外部 AI 工具并粘贴。再回到片语编辑和复制提示词，再次粘贴到外部工具。图片和文字共用剪贴板，须分别粘贴。多图模板须按页面说明在外部工具补充参考图，方括号中的内容须自行替换。
4. 导入结果：在外部工具保存优化后的 JPG／PNG／WebP，再点击“导入优化结果”。片语会另存一份新素材，记录对应原图、模板与提示词，不覆盖原图。
5. 检查对比：可并排或拖动滑杆查看前后变化，支持键盘调整滑杆。结果可复制，或加入当前草稿；以后从素材库“优化结果”进入可恢复对应原图、对比与已保存提示词。

“前后对比案例”内置商品柔光、美食暖光两组示例，无需联网。原图是 AI 生成的演示素材，优化图由图像编辑模型实际编辑，未使用滤镜假装 AI 结果。案例不保证其他工具得到相同效果。模板来源与案例制作说明见随包的 `AI模板与案例.md`。

## 导出素材

普通图片在素材包根目录，按 `001.png`、`002.png` 顺序排列；文案在 `文案.txt`。
实况位于所选设备的子目录，同样使用整体顺序编号。根据文件名序号合并选择，避免把实况封面和视频当作两份素材发布。`素材清单.json` 提供顺序和文件校验信息，不包含本机原始文件路径。

### iPhone

导出同名 JPG 和 MOV 配对资源。使用支持配对 Live Photo 的工具一起导入苹果相册。首个验证路径是 PhotoSync Windows Companion 与 iPhone 端 PhotoSync，需单独安装，部分功能可能收费。

参考：https://www.photosync-app.com/support/release-notes/photosync-companion-3-0-7-for-windows-released

不要只传其中一个文件，不要分别重命名，不要通过会压缩图片或去除元数据的方式传输。导入后检查苹果相册是否显示 LIVE，并长按播放。

### 标准安卓

导出 `MP.jpg` 结尾的单文件 Motion Photo。把完整文件复制到手机 `DCIM/Camera`，通过 Google Photos 等兼容相册打开。厂商原生相册的私有格式未纳入首版。

**iPhone 与安卓的真机兼容性均待验证。** 桌面预览与文件结构校验不能替代真机识别。社交平台是否接受实况文件也应在手机发布页面检查。

## 保存与备份

在“使用与存储”中查看本地资料库位置。关闭应用后备份整个资料库，恢复时完整还原同一目录。资料库包含草稿、导入图片与视频，以及处理后的素材。

导入时复制素材，裁切保留原始画面。删除草稿不会清理素材库，以免影响共享该素材的副本。卸载前请备份需要保留的资料。

## 失败处理

任务失败时查看提示，可重试或重新选择文件；磁盘空间不足时先清理空间。取消与失败不会生成成功提示，临时导出内容会清理。草稿保存失败会显示状态；退出保存失败时保留窗口。

应用不需要平台账号，没有云同步、自动发布或内置 AI 生成服务。创意提示词可由外部 AI 工具制作带字或插画效果，实际结果由你手动导入。
