## 当前工作流

- 草稿列表打开预览工作台；文案和图片都在微信／抖音预览中直接操作。工具条左侧提供返回与平台切换，右侧提供另存和导出；视频取材从素材库进入。
- 输入文案、导入或重排图片、裁切、视频截图、实况制作、切换平台后，预览立即反映草稿内容。
- 微信预览参考发表前编辑页：顶部发表栏、完整文案、九宫格及发布设置位置。抖音预览参考图文帖子：账号栏、竖图轮播、话题、正文与互动区示意。
- 账号、关注、互动、发表与微信发布设置仅作排版示意；未存储的发布设置明确标为“微信中设置”。
- 桌面截图位于 `output/playwright/`：原有预览为 `02` 至 `07`，全局素材库为 `08`，AI 复制流程、案例与结果对比为 `09` 至 `11`，标签与关键词搜索为 `12`。
