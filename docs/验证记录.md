# 验证记录

日期：2026-09-23。目标：Windows x64，片语 0.1.7 预览内编辑版。

## 本次交互变更

- 移除工作台左侧编辑栏。微信预览在文案区直接输入、九宫格提供“＋”图片占位；抖音预览点击正文编辑，图片画面提供“＋”占位。
- 图片拖动、单击编辑、视频取材、复制文案、移除、导出及自动保存继续可用。键盘排序移到预览图片本身。

## 当前工作流

- 草稿列表打开预览工作台；文案和图片都在微信／抖音预览中直接操作。顶部工具条提供标题、平台、视频取材、复制文案和导出。
- 输入文案、导入或重排图片、裁切、视频截图、实况制作、切换平台后，预览立即反映草稿内容。
- 微信预览参考发表前编辑页：顶部发表栏、完整文案、九宫格及发布设置位置。抖音预览参考图文帖子：账号栏、竖图轮播、话题、正文与互动区示意。
- 账号、关注、互动、发表与微信发布设置仅作排版示意；未存储的发布设置明确标为“微信中设置”。
- 桌面截图位于 `output/playwright/02-empty-preview.png`、`03-wechat-caption.png`、`05-wechat-preview.png` 和 `06-douyin-preview.png`。

- 微信和抖音参考预览保留完整文案、九宫格或逐张图片、大图与实况播放，不添加手机外框或状态栏。

桌面检查直接启动打包后的 EXE，使用独立临时资料库。子进程 PATH 仅保留 Windows 系统目录，实际截图与转码使用应用随包的 FFmpeg/FFprobe。测试固定了原生文件选择框的返回值，其余界面操作、文件保存、编码与导出均实际执行。

核心测试覆盖大量独立断言；“4 组”是测试分组数，并非只有四个操作。桌面截图和机器可读记录位于 `output/playwright/`，交付文件校验记录位于 `output/verification/`。
