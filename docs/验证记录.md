# 验证记录

日期：2026-09-23。目标：Windows x64，片语 0.1.5 预览直接操作版。

## 本次交互变更

- 微信九宫格中的图片支持鼠标按住拖到另一张的位置；抖音单图支持拖向左右或进度条目标位置。
- 单击预览图片打开裁切／旋转弹窗。微信实况保留独立播放按钮，避免单击编辑挤掉实况播放能力。
- 图片顺序修改仍写入同一份草稿并立即更新预览；左侧按钮继续支持键盘操作。

## 当前工作流

- 草稿列表打开预览工作台；左侧文案／图片工具切换，右侧微信或抖音预览持续可见。
- 输入文案、导入或重排图片、裁切、视频截图、实况制作、切换平台后，右侧立即反映草稿内容。导出仍从工作台右上方打开。
- 微信预览参考发表前编辑页：顶部发表栏、完整文案、九宫格及发布设置位置。抖音预览参考图文帖子：账号栏、竖图轮播、话题、正文与互动区示意。
- 账号、关注、互动、发表与微信发布设置仅作排版示意；未存储的发布设置明确标为“微信中设置”。
- 桌面截图位于 `output/playwright/02-live-caption.png`、`04-live-media.png`、`05-douyin-preview.png` 和 `06-wechat-preview.png`。

## 历史变更

- 0.1.3 建立了微信与抖音的参考预览卡片，0.1.4 沿用卡片版式。
- 0.1.2 的分步编辑页面在 0.1.4 合并到实时预览工作台。
- 0.1.1 移除了全局主题、外部字体与装饰图标；当前除参考预览卡片外仍使用原生控件。
- 草稿结构、IPC 与媒体处理逻辑未改变，已有草稿无需迁移。

## 已实现

- 草稿新建、复制、重命名、删除、搜索、平台筛选、自动保存与退出前保存。
- 图片导入、顺序调整、裁切、旋转、恢复原图；独立文案及剪贴板复制。
- 微信和抖音参考预览保留完整文案、九宫格或逐张图片、大图与实况播放，不添加手机外框或状态栏。
- 视频逐帧截图、最长三秒实况截取、封面选择与静音。
- 文件夹及 ZIP 素材导出，包含有序图片、文案、所选实况格式、导入说明及文件校验清单。

桌面检查直接启动打包后的 EXE，使用独立临时资料库。子进程 PATH 仅保留 Windows 系统目录，实际截图与转码使用应用随包的 FFmpeg/FFprobe。测试固定了原生文件选择框的返回值，其余界面操作、文件保存、编码与导出均实际执行。

核心测试覆盖大量独立断言；“4 组”是测试分组数，并非只有四个操作。桌面截图和机器可读记录位于 `output/playwright/`，交付文件校验记录位于 `output/verification/`。
