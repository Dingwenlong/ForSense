# 验证记录

## 本次预览变更

- 抖音图文参考所给图片帖子截图：账号栏、竖图轮播与页码、分段进度、从文案提取的话题、完整正文、相关搜索及互动区示意。
- 微信朋友圈参考所给发表前编辑页截图：顶部发表栏、文案、最多九张图片的三列网格，以及位置、提醒和可见范围设置栏。未存储的发布设置明确标为“微信中设置”。
- 两种预览只展示草稿里的图片、实况和文案，模拟元素不执行发布、不显示虚构互动数字；导出流程仍在独立区域。
- 桌面交互检查覆盖两种预览、图片翻页边界和键盘导航、话题高亮、素材包导出。微信完整预览截图位于 `output/playwright/05-wechat-card.png`，抖音正文及底部区域截图位于 `05-douyin-lower.png`。

## 本次流程变更

- 首次启动进入草稿列表；新建朋友圈或抖音图文后进入图片素材页。
- 图片素材、发布文案、预览导出为独立页面。顶部可跳转步骤，底部提供上一步或下一步，切换前保存草稿。
- 视频取材只从图片素材页进入；导出设置只从预览页打开。沿用原来的草稿与媒体格式，无需迁移。
- 打包后桌面流程覆盖初次创建、跨页保存、回退和跳转、视频取材、两种导出、关闭与重启恢复，以及不加图片的纯文案路径。

## 本次界面变更

- 删除主题样式表、外部字体、装饰图标、阴影、动画和宣传文案，改为系统字体及原生控件。
- 仅保留分栏、滚动、弹窗、媒体尺寸、裁切选区和可见选中状态所需的 `layout.css`。
- 操作改为明确的文字按钮，保留禁用状态、键盘焦点、弹窗关闭与确认。
- 数据结构、IPC 与媒体处理逻辑保持兼容，已有草稿无需迁移。

## 已实现

- 草稿新建、复制、重命名、删除、搜索、平台筛选、自动保存与退出前保存。
- 图片导入、顺序调整、裁切、旋转、恢复原图；独立文案及剪贴板复制。
- 纯图文排版预览，去除手机外框、状态栏、头像和仿平台互动按钮；完整文案、网格或逐张图片、大图与实况播放。
- 视频逐帧截图、最长三秒实况截取、封面选择与静音。
- 文件夹及 ZIP 素材导出，包含有序图片、文案、所选实况格式、导入说明及文件校验清单。

桌面检查直接启动打包后的 EXE，使用独立临时资料库。子进程 PATH 仅保留 Windows 系统目录，实际截图与转码使用应用随包的 FFmpeg/FFprobe。测试固定了原生文件选择框的返回值，其余界面操作、文件保存、编码与导出均实际执行。

核心测试覆盖大量独立断言；“4 组”是测试分组数，并非只有四个操作。桌面截图和机器可读记录位于 `output/playwright/`，交付文件校验记录位于 `output/verification/`。
