# 验证记录

日期：2026-09-28。目标：Windows x64，片语 0.2.2 统一草稿与标签搜索版。

## 本次交互变更

- 0.2.2 将新建草稿移至顶部素材库按钮右侧，通过 switch 为同一份素材切换微信／抖音预览；单个搜索框组合平台标签与关键词，移除重复说明与列表计数标题；工作台保留具名另存草稿，删除移至列表。移除顶部保存状态和使用入口，自动保存不变。

- 0.2.1 移除 AI 图片优化的顶部页签、预览编辑弹窗和选图弹窗入口，仅保留全局素材库图片详情中的入口；进入优化流程时导航仍归属全局素材库。其余 0.2.0 功能保留。

- 新增全局素材库，旧草稿素材自动可见；支持搜索、收藏、重命名、归档恢复、跨草稿选择和视频复用。预览“＋”打开包含本地导入和素材库选择的弹窗。
- 新增离线 AI 图片优化辅助页，按选择图片、选择模板、复制与对比分步使用。包含 20 个模板、2 组真实图像编辑案例和手动结果导入，不接入 AI 服务。
- 手动结果另存新素材，保留原图、模板与提示词；归档不影响已用草稿和对比引用。可并排或滑动比较，重启后可从素材库恢复结果记录。
- 沿用微信／抖音预览版式、拖放排序、单击裁切、视频取材和导出。复制操作增加写入后回读校验，系统拒绝剪贴板访问时明确失败，支持重试。

## 当前工作流

- 草稿列表打开预览工作台；文案和图片都在微信／抖音预览中直接操作。顶部工具条提供标题、平台、视频取材、复制文案和导出。
- 输入文案、导入或重排图片、裁切、视频截图、实况制作、切换平台后，预览立即反映草稿内容。
- 微信预览参考发表前编辑页：顶部发表栏、完整文案、九宫格及发布设置位置。抖音预览参考图文帖子：账号栏、竖图轮播、话题、正文与互动区示意。
- 账号、关注、互动、发表与微信发布设置仅作排版示意；未存储的发布设置明确标为“微信中设置”。
- 桌面截图位于 `output/playwright/`：原有预览为 `02` 至 `07`，全局素材库为 `08`，AI 复制流程、案例与结果对比为 `09` 至 `11`，标签与关键词搜索为 `12`。

桌面检查直接启动打包后的 EXE，使用独立临时资料库。子进程 PATH 仅保留 Windows 系统目录，实际截图与转码使用应用随包的 FFmpeg/FFprobe。测试固定了原生文件选择框的返回值，其余界面操作、文件保存、编码与导出均实际执行。
